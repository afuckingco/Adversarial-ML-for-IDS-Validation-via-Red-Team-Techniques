# Thesis Paper Draft

This directory contains the draft of the S2 thesis on adversarial machine learning for Intrusion Detection Systems.

## Contents
- `main.tex`: LaTeX source file for the thesis draft (based on IEEEtran template)
- `references.bib`: Bibliography file

## Usage
To compile the draft, run:
```bash
pdflatex main.tex
bibtex main.aux
pdflatex main.tex
pdflatex main.tex
```

This will produce `main.pdf`.

This is a draft version. The final thesis will be based on the research conducted in the other tasks.
